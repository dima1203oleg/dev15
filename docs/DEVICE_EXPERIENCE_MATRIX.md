# Device Experience Matrix

| Клас | Основна задача | Композиція | Interaction | Щільність |
|---|---|---|---|---|
| Телевізор | Ситуаційна обізнаність здалеку | Full-stage map, critical rail, ticker | Remote arrows / OK | Низька, великі типографічні рівні |
| Комп’ютер | Повний огляд | Story rail + core + live rail + timeline | Hover, keyboard, focus | Найвища |
| Ноутбук | Дослідження | Map 65% + info 35% + timeline | Click, collapse, scrub | Середня |
| Планшет | Просторова взаємодія | Core + selected layer + cards | Touch, swipe layer, tap | Середня |
| Смартфон | Відповідь для свого району | Personal risk card + simplified core + bottom nav | Tap, scroll | Мінімальна |
| Годинник | Glance за 1–2 секунди | Alert card | One primary action | Дуже низька |
| Авто | Безпечна мінімальна підказка | Current state + voice / shelter actions | Voice, large buttons | Дуже низька |
| AR / VR | Майбутня просторова сцена | Spatial primitives | 3D input / gaze / hand tracking | Майбутній контракт |

Одні й ті самі дані не означають однаковий layout. Presentation components ізольовані, а нормалізація даних спільна.
