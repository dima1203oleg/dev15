# Referral Engine

Production depth is exactly two levels: L1 and L2. L3+ receives zero compensation. Attribution is server-side and progresses from click → install → registration → payment → qualification. Partner-facing identities are masked labels only.

Self-referral is rejected at qualification even if a caller supplies a forged `LOCKED` attribution. A second-level id equal to the end user is not eligible for commission; attribution cannot be used to bypass the qualification boundary.
