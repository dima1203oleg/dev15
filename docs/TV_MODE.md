# Smart TV Mode

TV — окремий passive situational display, а не збільшений mobile dashboard. Планований route: `/tv` з власним shell без звичайної навігації.

Показує: велику карту, національний стан, критичні події та timeline/ticker. Партнерські метрики й дрібні account controls не показуються. Контраст і типографіка розраховані на перегляд здалеку; навігація має підтримувати remote arrows, OK та back.

Поточний прототип уже має окрему `TVScene` у multi-device lab. Підключення живого ThreatServer і dedicated route залишаються production integration work.
