# SIREN UA Smartphone Experience

Smartphone має власну presentation architecture `SIREN PERSONAL SPATIAL MODE`, а не зменшений desktop. На `/mobile` відкривається окремий mobile shell; на viewport до `767px` ця ж композиція використовується на головній сторінці.

Перший екран: мій район → ризик → freshness → напрямок → ETA → Personal Region Stack → деталі. Marketing та Partner контент не перекривають safety flow.

## Components

`MobileHeader`, `MobileRiskCard`, `MobileSpatialMap`, `MobileQuickActions`, `MobileTimeline`, `MobileShelters`, `MobileBottomSheet`, `MobileBottomNav`, `MobilePartnerHome`, `MobileProfile`.
