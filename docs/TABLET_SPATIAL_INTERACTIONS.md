# Tablet Spatial Interactions

## Touch model

- Tap a layer to focus it and update the context hierarchy.
- Swipe vertically across the deck to move through the layer sequence.
- Pinch inside the deck for bounded zoom; it never becomes an uncontrolled globe.
- Use the depth slider or the layers button to separate layers in a controlled range.
- Tap the region card to open the split region selector sheet.
- Tap an event to focus its context and timeline.

Map gesture capture is scoped to the deck so normal page scrolling remains available outside it. Every critical action also has a visible button and keyboard-equivalent path.

## Layer sequence

`LIVE_DATA → SHELTERS → PERSONAL_REGION → RISK → TRAJECTORY → EVENTS`.

Only two financial referral levels are represented in the partner view; the tablet does not expose an infinite network tree.
