# Mobile Mode

Mobile починається з питання: «Що відбувається зараз для мене?». Порядок: мій регіон → поточний ризик → timestamp → simplified spatial core → напрямок/ETA → укриття → partner.

Показується максимум 3–4 spatial layers, спрощуються тіні та motion, bottom navigation має Карта / Події / Укриття / Профіль. Критична інформація дублюється текстом; ETA завжди позначається як оцінка.
