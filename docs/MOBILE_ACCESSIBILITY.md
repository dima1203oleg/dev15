# Mobile Accessibility

- Critical state дублюється текстом, icon та кольором.
- Touch targets мають мінімум 44×44 CSS px.
- Personal map має keyboard-accessible button semantics і text label.
- Bottom sheet має `role=dialog`, але не блокує навігацію назавжди.
- Bottom navigation має `aria-label`; активний пункт визначений візуально й структурно.
- Reduced motion вимикає floating/pulse choreography.
