# Gap Analysis

## Implemented prototype foundations

- Dark navy / cyan / amber / critical-red visual system.
- CSS 3D and SVG layered intelligence stack with parallax and reduced-motion hooks.
- Desktop, tablet and mobile composition branches in the showcase.
- durable 2-level referral attribution, rank snapshots, cap validation and PostgreSQL ledger projections.
- Safety copy separates confirmed/estimated/predicted states in the map model.

## Missing for production

- Accessible, verified source repositories and real ThreatServer contract.
- Provider-specific identity, billing, attribution, fraud, KYC/AML and payment integrations.
- Real payout provider dispatch, settlement reconciliation and scheduled workers.
- Authoritative ThreatServer and geographic source.
- Staging-backed integration/security and provider contract suites; local unit/financial/E2E/accessibility/performance gates now exist.
- Staging-backed provider contract/security tests, CI/CD, secrets management and observability.

## Risks

The primary risks are stale or mislabelled threat information, missing external provider controls, and confusing explicitly labelled demo fixtures with authoritative safety or payable financial data.
