# Motion System

Motion carries meaning:

- нова подія — короткий pulse;
- вибраний регіон — elevation / focus;
- оновлена траєкторія — controlled dash flow;
- зміна ризику — зміна state layer, не декоративний спалах;
- перехід між шарами — плавний depth transition.

Не анімувати кожну картку, іконку або фон. `prefers-reduced-motion` вимикає нескінченні transitions і scroll choreography. Перший контент та CTA не залежать від завершення 3D-анімації.
